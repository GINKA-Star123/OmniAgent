### 1.1 契约与兼容边界

| 项目 | 本批行为 |
| --- | --- |
| 旧聊天/Voice 聚合字段 | 保留 reply_text/audio_url/audio_segment_urls；不把内部音频路径返回 HTTP |
| 新消费协议 | `/v2/outputs/{output_id}` 快照、`/events` 增量、`/acks` 回执；不使用 WebSocket |
| 生成 | 继续第六批 accepted/running/completed/failed/cancelled/unknown；生成完成才发布输出 |
| 资源 | text_ready、可选 audio_ready；本批没有真实对齐数据，timing_state 固定 unavailable，不伪造时间 |
| 消费 | pending → delivered → playback_started → playback_finished；delivered/started 可转 failed |
| 纯文本 | delivered 即消费终态，不要求播放回执 |
| speaking | 仅表示客户端报告的 playback_started 且尚未终止；audio_ready 不等于正在播放 |
| Presence | 默认关闭，用户显式启用；服务端时间、10 分钟冷却、10 秒候选有效期；继续规则开场，不调用主动 LLM/TTS |
| 图片观察 | 服务端可信信封，30 秒有效期，仅本轮 prompt；过期则本轮失败，不悄悄使用旧上下文 |
| Memory/上下文 | 图片轮次不自动落长期记忆，不将本轮 checkpoint/历史推进到后续轮次；纯文本轮次不变 |
| 本机扬声器 | 用户 HTTP 禁用服务端物理播放，沿用第五批启动校验；管理设备播放器不接用户回执，不新增全局停止入口 |

Presence 旧 `opening.should_speak` 改为 false，因为这里不生成音频、也不授权旧客户端自动发起 TTS；仍返回开场正文及兼容的旧 Live2D 数据字段，但不执行 Live2D。客户端未来可选择消费新协议，本批使用模拟消费者验收。

### 1.2 固定上限

这些是初始防护参数，不是压测结论。每输出最多 8 段，合计文字 UTF-8 32 KiB，协议快照 64 KiB；主体最多保留 24 份输出（含已过期槽位，满额拒绝，不静默驱逐）；每输出事件环 64 条、累计事件序号最多 128、ACK 幂等键 32 个；输出有效期 1 小时，不因 GET/ACK 续期。第六批主体根 4 MiB、operation 256、私有音频上限继续叠加生效。

消费者乱序缓冲最多 16 条、64 KiB，缺序/缺段等待 3 秒。生产版本一次提交全部准备好的段，模拟乱序是传输/消费顺序，不是宣称 Provider 已支持 token 流式。第九批才做保留期物理清理和容量优化；目前达到上限明确拒绝，不能直接清 key 绕过撤销屏障。

## 2. 新增 `aiagent/schemas/delivery.py`

**文件功能：**唯一公开的 V2 输出 schema。每个事件绑定完整作用域、单调 sequence 和确定 event_id；结构化 payload 禁止未知字段。回执的 consumer_id 是同一主体内的设备关联标签，绝不是认证身份。

```python
from __future__ import annotations

from typing import Annotated, Literal

from pydantic import BaseModel, ConfigDict, Field, model_validator

Name = Annotated[str, Field(min_length=1, max_length=128, pattern=r"^[A-Za-z0-9_.:-]+$")]
SessionName = Annotated[str, Field(min_length=1, max_length=256)]
Consumption = Literal["pending", "delivered", "playback_started", "playback_finished", "failed"]


class StrictModel(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True, strict=True)


class Segment(StrictModel):
    index: int = Field(ge=0, le=7)
    text: str = Field(min_length=1, max_length=32768)
    text_state: Literal["ready"] = "ready"
    audio_state: Literal["ready", "not_requested"] = "not_requested"
    audio_url: str | None = Field(default=None, max_length=256)
    timing_state: Literal["unavailable"] = "unavailable"
    consumption: Consumption = "pending"

    @model_validator(mode="after")
    def consistent_audio(self):
        if (self.audio_state == "ready") != (self.audio_url is not None):
            raise ValueError("delivery_audio_state_mismatch")
        if self.audio_url is not None:
            name = self.audio_url.removeprefix("/audio/")
            if not self.audio_url.startswith("/audio/") or not name or "/" in name or "\\" in name:
                raise ValueError("delivery_private_audio_url_required")
            if any(c not in "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789._-" for c in name):
                raise ValueError("delivery_invalid_audio_name")
        if self.audio_state == "not_requested" and self.consumption in {
            "playback_started", "playback_finished",
        }:
            raise ValueError("delivery_text_has_no_playback")
        return self


class Binding(StrictModel):
    schema_version: Literal[2] = 2
    session_id: SessionName
    operation_id: Name
    output_id: Name
    epoch: Name
    generation: int = Field(ge=1, lt=2**52)


class EventPayload(StrictModel):
    segment: Segment | None = None
    generation_state: Literal["completed"] | None = None


class DeliveryEvent(Binding):
    event_id: Name
    sequence: int = Field(ge=1, le=128)
    segment_index: int | None = Field(default=None, ge=0, le=7)
    kind: Literal["text_ready", "audio_ready", "output_completed", "consumption_changed"]
    payload: EventPayload

    @model_validator(mode="after")
    def check_payload(self):
        if self.kind == "output_completed":
            if self.segment_index is not None or self.payload.segment is not None:
                raise ValueError("delivery_invalid_completion")
            if self.payload.generation_state != "completed":
                raise ValueError("delivery_completion_state_required")
        elif (self.payload.segment is None or self.segment_index != self.payload.segment.index
              or self.payload.generation_state is not None):
            raise ValueError("delivery_segment_payload_required")
        return self


class Snapshot(Binding):
    generation_state: Literal["completed"] = "completed"
    segments: list[Segment] = Field(min_length=1, max_length=8)
    high_watermark: int = Field(ge=1, le=128)
    earliest_sequence: int = Field(ge=1, le=128)
    expires_at_ms: int = Field(ge=1)
    client_reported_speaking: bool


class EventPage(Binding):
    events: list[DeliveryEvent] = Field(max_length=64)
    high_watermark: int = Field(ge=1, le=128)
    next_after: int = Field(ge=0, le=128)
    has_more: bool


class AckRequest(StrictModel):
    schema_version: Literal[2] = 2
    operation_id: Name
    session_id: SessionName
    epoch: Name
    generation: int = Field(ge=1, lt=2**52)
    segment_index: int = Field(ge=0, le=7)
    client_event_id: Name
    consumer_id: Name
    expected_sequence: int = Field(ge=1, le=128)
    state: Literal["delivered", "playback_started", "playback_finished", "failed"]
```

**代码解释：**frozen 防止模型属性被意外重赋值，但 list 不是深不可变容器，因此服务读写均经 model_dump/deepcopy。generation_state 与 consumption 从类型上分开；URL 只能是服务端私有音频路径，实际 owner 授权仍在账本及下载路由检查，不靠正则证明权限。模型不携带真实用户凭据。

## 3. 新增 `aiagent/expression/delivery_store.py`

**文件功能：**在第六批同一个主体 JSON 根内保存输出、事件和 ACK。纯 publish 在 finish 的同次 CAS 内执行；GET 使用一次 GET+Redis TIME，快照和水位不会读出两代数据。ACK 使用同一 CAS，任何验证失败都不发布候选修改。

```python
from __future__ import annotations

import hashlib
from typing import Any

from pydantic import ValidationError

from aiagent.schemas.delivery import (
    AckRequest, DeliveryEvent, EventPage, EventPayload, Segment, Snapshot,
)
from aiagent.state.execution_ledger import ExecutionRejected, canonical, digest
from aiagent.state.shared_state import SharedStateUnavailableError

MAX_OUTPUTS = 24
MAX_EVENTS = 64
MAX_SEQUENCE = 128
MAX_ACKS = 32
OUTPUT_TTL_MS = 3_600_000


class DeliveryError(ExecutionRejected):
    def __init__(self, code: str, status: int = 409):
        super().__init__(code)
        self.status = status


def bucket(root: dict[str, Any]) -> dict[str, Any]:
    return root.setdefault("delivery_v7", {"schema": 1, "outputs": {}})


def binding(item: dict[str, Any]) -> dict[str, Any]:
    return {key: item[key] for key in (
        "schema_version", "session_id", "operation_id", "output_id", "epoch", "generation",
    )}


def public_snapshot(item: dict[str, Any]) -> Snapshot:
    return Snapshot(
        **binding(item), segments=[Segment.model_validate(s) for s in item["segments"]],
        high_watermark=item["sequence"], earliest_sequence=item["events"][0]["sequence"],
        expires_at_ms=item["expires_ms"],
        client_reported_speaking=any(s["consumption"] == "playback_started" for s in item["segments"]),
    )


def validate_delivery(root: dict[str, Any]) -> None:
    # Existing v6 roots have no v7 fields: absence is allowed, corruption is not.
    extension = root.get("delivery_v7")
    if extension is None:
        return
    try:
        if extension.get("schema") != 1 or not isinstance(extension.get("outputs"), dict):
            raise ValueError()
        if len(extension["outputs"]) > MAX_OUTPUTS:
            raise ValueError()
        for output_id, item in extension["outputs"].items():
            if output_id != item["output_id"] or len(item["events"]) > MAX_EVENTS:
                raise ValueError()
            if (type(item["sequence"]) is not int or not 1 <= item["sequence"] <= MAX_SEQUENCE
                    or not isinstance(item["acks"], dict) or len(item["acks"]) > MAX_ACKS
                    or not isinstance(item["consumer_id"], str) or len(item["consumer_id"]) > 128
                    or type(item["expires_ms"]) is not int or item["expires_ms"] <= 0):
                raise ValueError()
            if type(item["memory_revision"]) is not int or type(item["revoked"]) is not bool:
                raise ValueError()
            public_snapshot(item)
            expected = list(range(item["events"][0]["sequence"], item["sequence"] + 1))
            if [e["sequence"] for e in item["events"]] != expected:
                raise ValueError()
            if [s["index"] for s in item["segments"]] != list(range(len(item["segments"]))):
                raise ValueError()
            for event in item["events"]:
                parsed = DeliveryEvent.model_validate(event)
                if binding(event) != binding(item) or parsed.event_id != digest([output_id, parsed.sequence]):
                    raise ValueError()
            if len(canonical(public_snapshot(item).model_dump(mode="json")).encode()) > 65536:
                raise ValueError()
    except (ValueError, TypeError, KeyError, IndexError, AttributeError, ValidationError):
        raise SharedStateUnavailableError("delivery_state_invalid") from None


def emit(item: dict[str, Any], kind: str, segment: Segment | None = None) -> None:
    if item["sequence"] >= MAX_SEQUENCE:
        raise DeliveryError("delivery_event_budget_exceeded", 429)
    sequence = item["sequence"] + 1
    event = DeliveryEvent(
        **binding(item), sequence=sequence, event_id=digest([item["output_id"], sequence]),
        kind=kind, segment_index=segment.index if segment else None,
        payload=EventPayload(segment=segment, generation_state=None if segment else "completed"),
    )
    item["sequence"] = sequence
    item["events"] = (item["events"] + [event.model_dump(mode="json")])[-MAX_EVENTS:]


def publish(root, cap, now: int, draft: dict[str, Any]) -> None:
    outputs = bucket(root)["outputs"]
    output_id = draft["output_id"]
    if output_id in outputs:
        raise DeliveryError("delivery_output_id_conflict")
    if len(outputs) >= MAX_OUTPUTS:
        raise DeliveryError("delivery_output_capacity_exceeded", 429)
    segments = [Segment.model_validate(s) for s in draft["segments"]]
    if not 1 <= len(segments) <= 8 or [s.index for s in segments] != list(range(len(segments))):
        raise DeliveryError("delivery_invalid_segments")
    if sum(len(s.text.encode("utf-8")) for s in segments) > 32768:
        raise DeliveryError("delivery_text_budget_exceeded", 429)
    item = {
        "schema_version": 2, "session_id": cap.session_id, "operation_id": cap.operation_id,
        "output_id": output_id, "epoch": cap.epoch, "generation": cap.generation,
        "memory_revision": cap.memory_revision, "expires_ms": now + OUTPUT_TTL_MS,
        "segments": [s.model_dump(mode="json") for s in segments], "sequence": 0,
        "events": [], "acks": {}, "consumer_id": "", "revoked": False,
    }
    for segment in segments:
        emit(item, "text_ready", segment)
        if segment.audio_state == "ready":
            emit(item, "audio_ready", segment)
    emit(item, "output_completed")
    if len(canonical(public_snapshot(item).model_dump(mode="json")).encode()) > 65536:
        raise DeliveryError("delivery_snapshot_too_large", 429)
    outputs[output_id] = item
    root["operations"][cap.operation_id]["delivery_output_id"] = output_id


def live_item(root, now: int, output_id: str) -> dict[str, Any]:
    item = root.get("delivery_v7", {}).get("outputs", {}).get(output_id)
    if item is None:
        raise DeliveryError("delivery_not_found", 404)
    operation = root["operations"].get(item["operation_id"])
    session = root["sessions"].get(item["session_id"])
    if (item["revoked"] or now >= item["expires_ms"] or root["epoch"] != item["epoch"]
            or root["memory_revision"] != item["memory_revision"] or operation is None
            or operation["status"] != "completed" or session is None or session["closed"]
            or session["generation"] != item["generation"]
            or operation["generation"] != item["generation"]):
        raise DeliveryError("delivery_expired_or_revoked", 410)
    return item


class DeliveryStore:
    def __init__(self, ledger):
        self.ledger = ledger

    def read(self, user_id: str):
        raw, now = self.ledger.atomic.read(self.ledger.key(user_id))
        if not raw:
            raise DeliveryError("delivery_not_found", 404)
        return self.ledger._decode(raw, user_id), now

    def snapshot(self, user_id: str, output_id: str) -> Snapshot:
        root, now = self.read(user_id)
        return public_snapshot(live_item(root, now, output_id))

    def events(self, user_id: str, output_id: str, *, after: int, limit: int = 32) -> EventPage:
        if type(after) is not int or after < 0 or not 1 <= limit <= MAX_EVENTS:
            raise DeliveryError("delivery_invalid_cursor", 422)
        root, now = self.read(user_id)
        item = live_item(root, now, output_id)
        if after > item["sequence"]:
            raise DeliveryError("delivery_future_cursor")
        if after < item["events"][0]["sequence"] - 1:
            raise DeliveryError("delivery_cursor_expired_take_snapshot", 410)
        values = [e for e in item["events"] if e["sequence"] > after][:limit]
        next_after = values[-1]["sequence"] if values else after
        return EventPage(
            **binding(item), events=[DeliveryEvent.model_validate(e) for e in values],
            high_watermark=item["sequence"], next_after=next_after,
            has_more=next_after < item["sequence"],
        )

    def ack(self, user_id: str, output_id: str, request: AckRequest) -> Snapshot:
        payload_digest = hashlib.sha256(canonical(request.model_dump(mode="json")).encode()).hexdigest()

        def mutate(root, now):
            item = live_item(root, now, output_id)
            for key in ("operation_id", "session_id", "epoch", "generation"):
                if getattr(request, key) != item[key]:
                    raise DeliveryError("delivery_ack_scope_conflict")
            prior = item["acks"].get(request.client_event_id)
            if prior is not None:
                if prior != payload_digest:
                    raise DeliveryError("delivery_ack_idempotency_conflict")
                return public_snapshot(item)  # Retry precedes sequence comparison.
            if request.expected_sequence != item["sequence"]:
                raise DeliveryError("delivery_ack_sequence_conflict")
            if item["consumer_id"] not in {"", request.consumer_id}:
                raise DeliveryError("delivery_other_consumer")
            if request.segment_index >= len(item["segments"]):
                raise DeliveryError("delivery_segment_not_found", 404)
            segment = Segment.model_validate(item["segments"][request.segment_index])
            if segment.consumption == request.state:
                # Do not grow the idempotency map for no-op ACKs with invented keys.
                return public_snapshot(item)
            allowed = {
                "pending": {"delivered"},
                "delivered": {"playback_started", "failed"},
                "playback_started": {"playback_finished", "failed"},
                "playback_finished": set(), "failed": set(),
            }
            if request.state not in allowed[segment.consumption]:
                raise DeliveryError("delivery_invalid_transition")
            if request.state in {"playback_started", "playback_finished"} and segment.audio_state != "ready":
                raise DeliveryError("delivery_audio_not_ready")
            if request.state == "playback_started":
                previous = item["segments"][:request.segment_index]
                if any(s["audio_state"] == "ready" and s["consumption"] not in {
                    "playback_finished", "failed",
                } for s in previous):
                    raise DeliveryError("delivery_previous_audio_unfinished")
                if any(s["consumption"] == "playback_started" for s in item["segments"]):
                    raise DeliveryError("delivery_output_already_playing")
                # A single account may not start two server-tracked playbacks concurrently.
                for other_id in bucket(root)["outputs"]:
                    if other_id == output_id:
                        continue
                    try:
                        other = live_item(root, now, other_id)
                    except DeliveryError:
                        continue
                    if any(s["consumption"] == "playback_started" for s in other["segments"]):
                        raise DeliveryError("delivery_subject_already_playing")
            if len(item["acks"]) >= MAX_ACKS:
                raise DeliveryError("delivery_ack_budget_exceeded", 429)
            updated = Segment.model_validate({**segment.model_dump(), "consumption": request.state})
            item["segments"][segment.index] = updated.model_dump(mode="json")
            item["consumer_id"] = request.consumer_id
            item["acks"][request.client_event_id] = payload_digest
            emit(item, "consumption_changed", updated)
            return public_snapshot(item)

        _, deadline_now = self.read(user_id)
        # Obtain the deadline from a validated snapshot, then enforce it again in CAS.
        deadline = self.snapshot(user_id, output_id).expires_at_ms
        if deadline_now >= deadline:
            raise DeliveryError("delivery_expired_or_revoked", 410)
        return self.ledger.transaction(user_id, mutate, deadline_ms=deadline)
```

**代码解释：**event_id 由 output_id 和 sequence 生成，sequence 永不因环形截断复用。水位后的分页返回 next_after，不能把 high_watermark 当作已读取位置跳过剩余页。ACK 重试保存的是请求摘要而不是第二份输出，返回当前快照，因此重复 ACK 不倒退状态。首个真实状态转移绑定 consumer_id，本版没有设备租约接管；切换设备需重新生成输出，不伪称自动接管。

live_item 同时检查 epoch、session generation、Memory revision、operation completed、有效期和显式撤销。用户新回合/清历史/通话打断后，旧输出查询、ACK 和绑定音频都失效；已经传出的字节无法回收。客户端不发结束回执可能阻塞其他会话的播放准入，最长至输出过期；本批不凭服务器猜测自动宣称“已播完”。

## 4. 新增 `aiagent/expression/delivery_builder.py`

**文件功能：**将第六批已登记的私有资源转换成 V2 draft。严格检查 TTS 平行数组，禁止 zip 截断或把未登记路径包装成 URL。保持旧 reply_text，不强迫分段文字拼接与它逐字一致（TTS 可能规范化标点）；对外明确 segment.text 表示该段实际送入合成的文字。

```python
from __future__ import annotations

from aiagent.schemas.delivery import Segment
from aiagent.state.execution_ledger import ExecutionRejected


def build_delivery(output, cap, objects: dict) -> dict:
    packet = output.packet
    output_key = f"output:{output.output_id}"
    if output_key not in objects:
        raise ExecutionRejected("delivery_private_output_required")
    urls = list(packet.audio_segment_urls)
    texts = list(packet.audio_segment_texts)
    if packet.audio_url and not urls:
        urls = [packet.audio_url]
        texts = [packet.reply_text]
    if urls:
        if not 1 <= len(urls) <= 8 or len(urls) != len(texts):
            raise ExecutionRejected("delivery_audio_text_count_mismatch")
        segments = []
        for index, (url, text) in enumerate(zip(urls, texts, strict=True)):
            segment = Segment(index=index, text=text, audio_state="ready", audio_url=url)
            descriptor = objects.get(f"audio:{url.removeprefix('/audio/')}")
            if descriptor is None or descriptor.get("kind") != "audio":
                raise ExecutionRejected("delivery_unregistered_audio")
            descriptor["delivery_output_id"] = output.output_id
            segments.append(segment)
    else:
        if packet.audio_path or packet.audio_segments:
            raise ExecutionRejected("delivery_audio_missing_private_url")
        segments = [Segment(index=0, text=packet.reply_text)]
    if sum(len(s.text.encode("utf-8")) for s in segments) > 32768:
        raise ExecutionRejected("delivery_text_budget_exceeded")
    objects[output_key]["delivery_output_id"] = output.output_id
    packet.metadata.update({
        "delivery_schema_version": "2",
        "delivery_snapshot_url": f"/v2/outputs/{output.output_id}",
        "delivery_operation_id": cap.operation_id,
        "delivery_segment_text_semantics": "tts_input_or_reply_text",
        "delivery_timing_state": "unavailable",
    })
```

## 5. 新增 `aiagent/presence/admission.py`

**文件功能：**Presence 偏好、用户回合抢占和最终规则开场提交。所有函数在 ledger CAS 回调里只做有界计算，不调用模型、Redis、文件或播放器。独立 PresenceStore 不再是真源。

```python
from __future__ import annotations

from datetime import UTC, datetime

from pydantic import BaseModel, ConfigDict, Field

from aiagent.expression.delivery_store import DeliveryError, bucket, live_item
from aiagent.presence.live2d_mapper import build_live2d_presence
from aiagent.presence.models import OpeningPayload, PresencePayload, SessionOpenResponse, SessionSnapshot

    choose_opening_kind, generate_opening_text, update_snapshot_after_open,

from aiagent.schemas.delivery import Segment
from aiagent.state.execution_ledger import ExecutionRejected, digest
from aiagent.state.shared_state import SharedStateUnavailableError

COOLDOWN_MS = 600_000
CANDIDATE_MS = 10_000
PRESENCE_SESSION = "p7:opening"


class PresenceSuppressed(ExecutionRejected):
    pass


class PreferenceRequest(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True)
    enabled: bool
    expected_revision: int = Field(ge=0, lt=2**52)


def preference(root):
    return root.setdefault("presence_v7", {
        "schema": 1, "enabled": False, "revision": 0, "cooldown_until_ms": 0, "snapshot": {},
    })


def validate_presence(root):
    item = root.get("presence_v7")
    if item is None:
        return
    try:
        if (item["schema"] != 1 or type(item["enabled"]) is not bool
                or type(item["revision"]) is not int or not 0 <= item["revision"] < 2**52
                or type(item["cooldown_until_ms"]) is not int or item["cooldown_until_ms"] < 0
                or not isinstance(item["snapshot"], dict)):
            raise ValueError()
        if item["snapshot"]:
            snapshot = SessionSnapshot.model_validate(item["snapshot"])
            if snapshot.user_id != root["owner"]:
                raise ValueError()
    except (ValueError, TypeError, KeyError):
        raise SharedStateUnavailableError("presence_state_invalid") from None


def revoke_presence(root, now):
    for operation in root["operations"].values():
        if operation["kind"] != "presence":
            continue
        if operation["status"] in {"accepted", "running"}:
            operation["status"] = "cancelled"
            operation["finished_ms"] = now
            session = root["sessions"][operation["session_id"]]
            if session["active"] == operation["operation_id"]:
                session["active"] = ""
                session["generation"] += 1
        output_id = operation.get("delivery_output_id")
        item = bucket(root)["outputs"].get(output_id)
        if item:
            item["revoked"] = True


def check_presence(root, now):
    item = preference(root)
    if not item["enabled"]:
        raise PresenceSuppressed("presence_disabled")
    if now < item["cooldown_until_ms"]:
        raise PresenceSuppressed("presence_cooldown")
    if any(op["kind"] == "user" and op["status"] in {"accepted", "running"}
           and now < op["deadline_ms"] for op in root["operations"].values()):
        raise PresenceSuppressed("presence_user_busy")
    for output_id in bucket(root)["outputs"]:
        try:
            output = live_item(root, now, output_id)
        except DeliveryError:
            continue
        if any(s["consumption"] == "playback_started" for s in output["segments"]):
            raise PresenceSuppressed("presence_playback_busy")


def before_admission(root, now, kind):
    if kind == "user":
        revoke_presence(root, now)
    else:
        check_presence(root, now)


def update_preference(ledger, user_id: str, request: PreferenceRequest):
    def mutate(root, now):
        item = preference(root)
        if request.expected_revision != item["revision"]:
            raise ExecutionRejected("presence_preference_revision_conflict")
        if item["enabled"] == request.enabled:
            return {"enabled": item["enabled"], "revision": item["revision"]}
        if item["revision"] >= 2**52 - 1:
            raise ExecutionRejected("presence_preference_revision_exhausted")
        item["enabled"] = request.enabled
        item["revision"] += 1
        if not request.enabled:
            revoke_presence(root, now)
        return {"enabled": item["enabled"], "revision": item["revision"]}
    return ledger.transaction(user_id, mutate)


def commit_opening(root, cap, now, request):
    record = root["operations"][cap.operation_id]
    if record["kind"] != "presence" or cap.session_id != PRESENCE_SESSION:
        raise ExecutionRejected("presence_invalid_operation")
    check_presence(root, now)
    if now >= record["created_ms"] + CANDIDATE_MS:
        raise PresenceSuppressed("presence_candidate_expired")
    item = preference(root)
    snapshot = SessionSnapshot.model_validate(item["snapshot"]) if item["snapshot"] else SessionSnapshot(
        user_id=cap.user_id, username=request["username"],
    )
    instant = datetime.fromtimestamp(now / 1000, UTC)
    snapshot.mood = update_mood_for_time(instant, snapshot.mood)
    state = choose_presence_state(instant, snapshot.mood)
    kind = choose_opening_kind(instant, snapshot)
    text = generate_opening_text(kind=kind, now=instant, snapshot=snapshot)
    updated = update_snapshot_after_open(snapshot=snapshot, now=instant, recent_topic=request["recent_topic"])
    updated.mood = snapshot.mood
    updated.last_opening_shown_at = instant
    item["snapshot"] = updated.model_dump(mode="json")
    item["cooldown_until_ms"] = now + COOLDOWN_MS
    output_id = digest([cap.operation_id, "presence-output-v7"])
    response = SessionOpenResponse(
        opening=OpeningPayload(kind=kind, text=text, should_speak=False),
        presence=PresencePayload(
            state=state, mood=mood_label(snapshot.mood), energy=round(snapshot.mood.energy, 3),
            fatigue=round(snapshot.mood.fatigue, 3), curiosity=round(snapshot.mood.curiosity, 3),
        ),
        live2d=build_live2d_presence(state=state, kind=kind, mood=snapshot.mood),
        memory={"open_count": updated.open_count, "last_topic": updated.last_topic,
                "has_unfinished_hint": bool(updated.unfinished_hint), "opening_suppressed": False},
    ).model_dump(mode="json")
    response.update({"output_id": output_id, "operation_id": cap.operation_id,
                     "delivery_snapshot_url": f"/v2/outputs/{output_id}"})
    return ({"output_id": output_id, "body": response}, {
        "output_id": output_id, "segments": [Segment(index=0, text=text).model_dump(mode="json")],
    })
```

**代码解释：**用户新操作的准入与主动输出撤销是同一次 CAS；用户准入失败不发布撤销候选。开场在 finish 时复查 enabled/忙碌/有效期，并在同次 CAS 更新冷却、snapshot 和输出。不提前把 `open_count`、mood 或冷却写出去，CAS 重试也不会累加两次。重复开场采用固定 session 与服务端时间桶幂等，既有 operation 上限仍约束主动请求。客户端时间不进入选择或有效期。

### 7.1 完整替换 `aiagent/presence/service.py`

**文件功能：**继续使用原来的规则生成器，但准入、冷却、偏好和输出都进共享账本。这个同步方法由 API 的同步路由在线程池运行，不在 async handler 中同步访问 Redis。

```python
from __future__ import annotations

from aiagent.presence.admission import (
    CANDIDATE_MS, PRESENCE_SESSION, PresenceSuppressed,
)
from aiagent.state.execution_ledger import ExecutionRejected, digest


class PresenceService:
    def __init__(self, ledger):
        self.ledger = ledger

    def open_session(self, req) -> dict:
        # Redis TIME / LocalAtomic test clock; never trust req.client_time.
        _, now = self.ledger.atomic.read(self.ledger.key(req.user_id))
        payload = {"username": req.username.strip()[:80], "recent_topic": req.recent_topic.strip()[:120]}
        try:
            admission = self.ledger.begin(
                user_id=req.user_id, session_id=PRESENCE_SESSION,
                idempotency_key=f"opening:{now // CANDIDATE_MS}",
                payload_digest=digest(payload), kind="presence", deadline_seconds=CANDIDATE_MS // 1000,
            )
        except PresenceSuppressed as exc:
            return self.silent(str(exc))
        if not admission.created:
            # Coalesce, do not replay a second visible proactive opening to another caller.
            return self.silent("presence_coalesced")
        cap = admission.capability
        try:
            self.ledger.start(cap)
            committed = self.ledger.finish(cap, result={}, presence_request=payload)
            return committed["body"]
        except PresenceSuppressed as exc:
            self.ledger.terminal(cap, "failed")
            return self.silent(str(exc))
        except ExecutionRejected:
            # User preemption/expiry is a real conflict, never speak fallback text.
            raise
        except BaseException:
            # An uncertain commit must not be retried into another proactive operation.
            raise

    @staticmethod
    def silent(reason: str) -> dict:
        return {
            "ok": True, "opening": {"kind": "short_return", "text": "", "should_speak": False},
            "presence": {"state": "idle", "mood": "neutral", "energy": 0.5,
                         "fatigue": 0.2, "curiosity": 0.6},
            "live2d": {"expression": "neutral", "motion": "idle", "suggested_delay_ms": 0,
                       "eye": {}, "mouth": {"mode": "idle"}, "scene": {}},
            "memory": {"opening_suppressed": True},
            "suppressed_reason": reason, "output_id": None,
        }
```

**代码解释：**同一 10 秒桶不同正文会触发幂等冲突（409），不会拿旧用户名/话题当作新请求成功。正常重复返回静默合并，不把一次开场展示两次；只有一个 CAS 成功的调用获得正文。被用户抢先、服务器故障等不返回“我刚刚待机”的伪成功。silent 的旧 live2d 字段保留结构但为 idle，不触发语音，不是新 Live2D 方案。

## 8. 新增 `aiagent/perception/observations.py`

**文件功能：**为当前 Vision chat_context 赋予来源、时效和用途；不重写 Vision 图的低置信策略/GIF 抽样/角色候选字段。分数明确为未校准模型分数，不能用作真实用户身份验证。正文摘要是完整性关联，不是脱敏或授权。

```python
from __future__ import annotations

import hashlib
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field, model_validator

from aiagent.state.execution_ledger import ExecutionRejected


class Observation(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True, frozen=True)
    schema_version: Literal[1] = 1
    source: Literal["vision"] = "vision"
    category: Literal["image_scene"] = "image_scene"
    score_semantics: Literal["uncalibrated_model_score_not_identity"] = "uncalibrated_model_score_not_identity"
    score: float | None = Field(default=None, ge=0, le=1)
    allowed_uses: tuple[Literal["prompt"], ...] = ("prompt",)
    user_id: str
    session_id: str
    operation_id: str
    epoch: str
    generation: int
    observed_at_ms: int
    received_at_ms: int
    expires_at_ms: int
    content_sha256: str = Field(pattern=r"^[a-f0-9]{64}$")
    content: str = Field(min_length=1, max_length=16384)

    @model_validator(mode="after")
    def validate_envelope(self):
        if (self.observed_at_ms > self.received_at_ms
                or not self.received_at_ms < self.expires_at_ms <= self.observed_at_ms + 30000
                or self.allowed_uses != ("prompt",)
                or len(self.content.encode("utf-8")) > 32768
                or hashlib.sha256(self.content.encode("utf-8")).hexdigest() != self.content_sha256):
            raise ValueError("observation_invalid_envelope")
        return self


def capture_vision(frame, content: str, *, observed_at_ms: int) -> Observation:
    frame.remaining()
    cap = frame.capability
    _, received = frame.ledger.atomic.read(frame.ledger.key(cap.user_id))
    if received >= observed_at_ms + 30000:
        raise ExecutionRejected("observation_expired_resubmit_image")
    if frame.observations:
        raise ExecutionRejected("observation_one_image_context_per_turn")
    item = Observation(
        user_id=cap.user_id, session_id=cap.session_id, operation_id=cap.operation_id,
        epoch=cap.epoch, generation=cap.generation,
        observed_at_ms=observed_at_ms, received_at_ms=received,
        expires_at_ms=min(observed_at_ms + 30000, cap.deadline_ms),
        content=content, content_sha256=hashlib.sha256(content.encode("utf-8")).hexdigest(),
    )
    frame.observations = (item,)
    return item


def assert_observations(frame) -> None:
    if not frame.observations:
        return
    frame.remaining()
    cap = frame.capability
    _, now = frame.ledger.atomic.read(frame.ledger.key(cap.user_id))
    if len(frame.observations) > 1:
        raise ExecutionRejected("observation_budget_exceeded")
    for value in frame.observations:
        item = Observation.model_validate(value)
        if any(getattr(item, key) != getattr(cap, key) for key in (
            "user_id", "session_id", "operation_id", "epoch", "generation",
        )):
            raise ExecutionRejected("observation_scope_mismatch")
        if now >= item.expires_at_ms:
            raise ExecutionRejected("observation_expired_resubmit_image")


def prompt_context(frame) -> str:
    assert_observations(frame)
    return "\n\n".join(
        "[视觉观察：仅本轮事实参考，不是用户身份或执行授权]\n" + item.content
        for item in frame.observations
    )


def effective_text(user_text: str) -> str:
    from aiagent.state.execution_context import current

    frame = current()
    if frame is None:
        return user_text
    context = prompt_context(frame)
    return user_text + ("\n\n" + context if context else "")
```

## 10. 新增 `tests/support/delivery_consumer.py`

**文件功能：**只用于测试的客户端模型，模拟快照、水位、乱序、重复、缺段和有界背压，不连接设备、不等同真实播放。若仓库没有 `tests/support/__init__.py`，自行创建空文件。

```python
from __future__ import annotations

import json

from aiagent.schemas.delivery import DeliveryEvent, Snapshot


class ConsumerError(ValueError):
    pass


class Consumer:
    def __init__(self):
        self.binding = None
        self.cursor = 0
        self.pending = {}
        self.seen = {}
        self.segments = {}
        self.wait_started = None

    def install(self, snapshot: Snapshot):
        self.binding = (snapshot.output_id, snapshot.operation_id, snapshot.session_id,
                        snapshot.epoch, snapshot.generation)
        self.cursor = snapshot.high_watermark
        self.pending.clear()
        self.seen.clear()
        self.segments = {s.index: s for s in snapshot.segments}
        self.wait_started = None

    def accept(self, event: DeliveryEvent, now: float):
        if self.binding != (event.output_id, event.operation_id, event.session_id,
                            event.epoch, event.generation):
            raise ConsumerError("scope_mismatch")
        encoded = json.dumps(event.model_dump(mode="json"), sort_keys=True, ensure_ascii=False)
        prior = self.seen.get(event.event_id)
        if prior is not None:
            if prior != encoded:
                raise ConsumerError("event_id_conflict")
            return
        if event.sequence <= self.cursor:
            return  # May predate the snapshot; the snapshot remains authoritative.
        if event.sequence in self.pending:
            if self.pending[event.sequence][1] != encoded:
                raise ConsumerError("sequence_conflict")
            return
        if len(self.pending) >= 16 or sum(len(raw.encode()) for _, raw in self.pending.values()) + len(encoded.encode()) > 65536:
            raise ConsumerError("backpressure_resnapshot")
        self.pending[event.sequence] = (event, encoded)
        while self.cursor + 1 in self.pending:
            value, raw = self.pending.pop(self.cursor + 1)
            if value.payload.segment is not None:
                if value.segment_index not in self.segments:
                    raise ConsumerError("missing_segment_resnapshot")
                self.segments[value.segment_index] = value.payload.segment
            self.cursor += 1
            self.seen[value.event_id] = raw
            if len(self.seen) > 64:
                self.seen.pop(next(iter(self.seen)))
        self.wait_started = self.wait_started if self.pending and self.wait_started is not None else (now if self.pending else None)

    def check_timeout(self, now: float):
        if self.wait_started is not None and now - self.wait_started >= 3:
            raise ConsumerError("missing_sequence_resnapshot")
```

**代码解释：**先安装一致快照再从 high_watermark 拉事件，解决“拉快照期间新事件到达”的竞态。乱序事件进入有限 pending，重复相同 event_id 不重复应用；同序号不同内容冲突。超过 3 秒/缓冲上限要求重新获取快照，不猜测丢失内容。seen 最多 64 条；已被快照覆盖或被淘汰的旧重复只丢弃，不承诺无限期检测其内容冲突。该类只处理快照后的增量，不以模拟器证明真正网络推送或实际设备播放。

## 14. 新增 `tests/integration/test_delivery_v7_redis.py`

**文件功能：**两个独立进程连接同一个真实 Redis，以相同 ACK 水位竞争；再让两个进程竞争一次规则开场。采用随机前缀、显式测试主体，只删除本次测试的确切 key，不调用 FLUSHDB。未配置 `BATCH07_REDIS_URL` 时跳过；配置后连接/ACL/协议失败即测试失败，不回退本地。

```python
from __future__ import annotations

import multiprocessing as mp
import os
import uuid

import pytest
from redis import Redis

from aiagent.expression.delivery_store import DeliveryError, DeliveryStore
from aiagent.presence.admission import PreferenceRequest, update_preference
from aiagent.presence.models import SessionOpenRequest
from aiagent.presence.service import PresenceService
from aiagent.schemas.delivery import AckRequest
from aiagent.state.execution_ledger import ExecutionLedger, ExecutionRejected, RedisAtomic
from tests.unit.test_delivery_v7 import produce


def worker_ack(url, prefix, output, payload, index, gate, queue):
    client = Redis.from_url(url)
    ledger = ExecutionLedger(RedisAtomic(client), prefix=prefix)
    try:
        gate.wait(10)
        body = AckRequest(**{**payload, "client_event_id": f"ack-{index}", "consumer_id": f"device-{index}"})
        DeliveryStore(ledger).ack("redis-test-user", output, body)
        queue.put("committed")
    except DeliveryError:
        queue.put("conflict")
    except BaseException as exc:
        queue.put(f"error:{type(exc).__name__}")
    finally:
        client.close()


def worker_open(url, prefix, gate, queue):
    client = Redis.from_url(url)
    ledger = ExecutionLedger(RedisAtomic(client), prefix=prefix)
    try:
        gate.wait(10)
        response = PresenceService(ledger).open_session(SessionOpenRequest(user_id="redis-test-user"))
        queue.put("opened" if response["opening"]["text"] else "suppressed")
    except ExecutionRejected:
        queue.put("suppressed")
    except BaseException as exc:
        queue.put(f"error:{type(exc).__name__}")
    finally:
        client.close()


def run_pair(target, args):
    ctx = mp.get_context("spawn")
    gate, queue = ctx.Event(), ctx.Queue()
    processes = [ctx.Process(target=target, args=(*args, n, gate, queue)) for n in range(2)]
    try:
        for process in processes:
            process.start()
        gate.set()
        values = [queue.get(timeout=30) for _ in processes]
        for process in processes:
            process.join(30)
            assert process.exitcode == 0
        return values
    finally:
        for process in processes:
            if process.is_alive():
                process.terminate()
            if process.pid is not None:
                process.join(10)
        queue.close()


def open_adapter(url, prefix, index, gate, queue):
    del index
    worker_open(url, prefix, gate, queue)


@pytest.fixture
def redis_case():
    url = os.environ.get("BATCH07_REDIS_URL")
    if not url:
        pytest.skip("set BATCH07_REDIS_URL to an isolated Redis instance")
    client = Redis.from_url(url, socket_connect_timeout=5, socket_timeout=5)
    client.ping()
    prefix = f"batch07-{uuid.uuid4().hex}"
    ledger = ExecutionLedger(RedisAtomic(client), prefix=prefix)
    try:
        yield url, prefix, ledger
    finally:
        client.delete(ledger.key("redis-test-user"))
        client.close()


def test_two_processes_compete_for_one_ack(redis_case):
    url, prefix, ledger = redis_case
    _, output = produce(ledger, user="redis-test-user", session="s1", audio=True)
    snapshot = DeliveryStore(ledger).snapshot("redis-test-user", output)
    payload = {
        "operation_id": snapshot.operation_id, "session_id": snapshot.session_id,
        "epoch": snapshot.epoch, "generation": snapshot.generation, "segment_index": 0,
        "expected_sequence": snapshot.high_watermark, "state": "delivered",
    }
    assert sorted(run_pair(worker_ack, (url, prefix, output, payload))) == ["committed", "conflict"]
    assert DeliveryStore(ledger).snapshot("redis-test-user", output).segments[0].consumption == "delivered"


def test_two_processes_proactive_open_only_one(redis_case):
    url, prefix, ledger = redis_case
    update_preference(ledger, "redis-test-user", PreferenceRequest(enabled=True, expected_revision=0))
    values = run_pair(open_adapter, (url, prefix))
    assert sorted(values) == ["opened", "suppressed"]
    assert ledger.snapshot("redis-test-user")["presence_v7"]["snapshot"]["open_count"] == 1
```

**测试解释：**真实 Redis 的 TIME、Lua CAS、进程隔离都会执行，但这不是 RedisSaver 或 RedisJSON 功能测试；第六批 RedisSaver 联合测试仍需单独运行。测试 URL 必须是专用可写测试实例，不提供默认生产地址。若进程异常结果是 `error:*` 或超时，测试应失败；不因为 Redis 不可用自动 skip。

## 15. 兼容性、部署与残余风险

1. 第五、六批代码先落地并通过其离线与共享状态验证，才能实施本批。尤其检查 `ExecutionLedger.transaction` 的 Redis CAS 同时比较原值与服务端 deadline；不能用本地锁替代多 Worker 原子性。
2. 本批扩展根仍用原 key，部署时先停写并同时升级所有 API/Worker，不允许 V6/V7 混跑：旧 Worker 不认识扩展、可能继续发布无 V2 约束的新输出。先备份专用环境和核对回滚窗口；不改根 key 的 schema 号不代表可以随意混版。
3. 回滚需先停写，确认没有依赖 V2 状态的请求，然后恢复第六批代码。旧版本会忽略扩展；**回滚后不再保证 V2 新资源的 generation 撤销、Presence 偏好及回执**，因此必须关停相关入口/用户流量并明确告知，不能在多用户公网直接回滚后宣称同等安全。不可清空根 key“恢复服务”，那会丢撤销屏障和记忆引用。
4. 一主体最多 24 份输出且过期后仍占槽，当前实现适合受控有限流量的验收，不适合长期开放生产；达到容量即 429。第九批完成受控清理与容量监测前，不能把这一实现当作可持续上线方案。类似地，第六批 operation 256、GC 队列和私有文件仍有自己的容量问题。
5. 如果模型输出空字符串、分段与音频数组不匹配、没有登记的 URL，提交明确失败；没有把这些情况伪造为正常分段。Provider 失败后的旧降级语义应保留并在集成测试中核对。
6. 图片轮次关闭自动 Memory 与跨轮历史是有意的保守行为，会降低多轮图片对话体验；用户可在后续纯文本轮次重述并确认。后续若需要跨轮视觉，需要持久化带 TTL 的派生摘要及其传播关系，并在全部消费点复核，不是把 `history_pair` 恢复即可。
7. 本批只控制当前操作的观察 TTL 与用途，不是 Prompt Injection 安全解决方案；视觉、RAG、摘要、模型输出仍属于不可信数据。也没有针对恶意 Python 主进程或已外发内容的防护。Rust 组件及跨来源污点处理属于第八批。
8. 老文件接口的历史资源与旧本机管理播放器仍是迁移期间边界；用户 HTTP 按第五批配置禁用物理服务端播放，不能把进程级 stop 接入用户回执。音频下载虽在文件打开前检查，可在成功检查后同时发生撤销；已经返回/打开的内容无法撤回，不承诺事务性取消正在下载的字节。
9. 不自动调用真实外部 Provider、不改数据库、不产生真实数据；测试数据都应为合成内容。消费者 ACK 是客户端自报，不能证明播放设备成功或用户听到。
