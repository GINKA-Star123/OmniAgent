# V1.2 第九批代码交付：任务故障恢复与数据生命周期

> 本文仅提供手动实施代码、说明与验证指令。本次不修改业务、配置、测试文件，不运行 Redis、Worker、Provider、容器或清理操作；文档存在不代表代码已经实施或验收。

## 1. 范围、前提与现状

依据 `v1.2-batches-05-10-revised-roadmap.md` 第九节，复用既有 `CloudTaskQueue`，处理入队原子性、领取租约、未知结果和受限清理；继续使用第六批共享账本与第七批输出协议。第八批对自动 `chat_turn` 记忆写入仍是禁用状态，本批不能在缺少跨进程批准证明的情况下悄悄打开。

本次核对到的真实现状：

1. `cloud/task_queue.py` 先写 unique、再写 task、再入队；`pop()` 使用 BLPOP 后才 `start()`，进程在两步之间崩溃可丢任务。`recover_stale_running()` 会扫描并直接重新排队，无法证明外部任务没有执行。
2. `apps/worker/main.py` 的知识/角色图库重建包含文件/外部副作用，旧实现无可验证的 stage-publish fence；即便 Redis 锁或新租约过期，也不能阻止已经启动的线程继续修改外部资源。
3. `cloud.redis_client.get_redis_client()` 连接失败返回 None，而旧队列将 None 当本地队列；多进程/云端会静默分叉。
4. 第六批 `ApprovedMemoryWrite` 使用进程内随机 HMAC 密钥，不能原样交给另一个 Worker 验证。第八批为了防注入禁用了自动记忆写入；不能为满足“有队列”而恢复模型生成记忆。
5. 第五至八批的多个关键文件目前仍只存在交付 MD，真实工作区没有可直接调用的 ledger/delivery/guard 模块。先手写并验证这些前置，尤其是原子 CAS、可信主体、私有资源和第八批限制。本文基于这些最终契约，不能把文档当作运行代码。

**本批交付范围和不冒充的能力：**

| 项目 | 本文提供 | 边界 |
| --- | --- | --- |
| 任务记录 | Redis 单实例上的原子提交、幂等载荷比较、领取/租约与终态 CAS | 不是全局 exactly-once；不支持 Redis Cluster 跨 slot |
| 未知结果 | 过期或丢响应标 unknown，不自动重放 | 已经进入外部系统的工作可能仍继续 |
| 第七批容量 | 账本内有界清理过期输出及短期墓碑 | 不自动删除未找到的物理音频/模型文件 |
| 记忆 | 保留禁用自动 chat_turn；说明跨进程批准与删除屏障的前置 | 本文不假称解决跨进程持久批准或物理 Mem0 回收 |
| 性能 | 复用第六批基线脚本，给统计对照与采证要求 | 不预先虚构优化幅度、Token 和成本 |

**重要上线门槛：**旧队列和新版协议不能混跑；必须先关闭提交入口、停止并排空旧 Worker，保留旧任务并确认外部状态，再一次性升级。由于旧知识/视觉重建缺少可靠发布 fence，本文件的 Worker 接线默认不开放这两个真实重建处理器；只有完成第六批不可变制品与发布资格验证、并审阅对应任务类型的幂等边界后，才能手工加入允许列表。这样避免用一个新租约包装旧危险副作用后误以为已经修复。

## 2. 任务协议约定

第九批 Redis 路径要求**显式 Redis**，不得使用连接失败后本地 fallback；本机单进程开发若使用原队列，仍只能视为旧功能演示，不能作为本协议验收。复用原 `CloudTaskQueue` 的同一 logical queue、任务 hash、待处理 list；新增租约有序集合及安全去重索引作为同一队列的索引，不引入第二套任务系统。

| 状态 | 解释 |
| --- | --- |
| queued | 任务记录与队列占位已经通过同一 Redis Lua 提交 |
| running | 原子领取并分配不可猜测 token 与服务端时间租约 |
| succeeded | 匹配 token 且租约未到期的已知成功结果 |
| cancelled | 明确取消资格；不能据此宣称外部线程已停止 |
| unknown | Worker 退出、租约超时或提交结果不确定；禁止自动重跑 |

本版 `unique_key` + owner + queue + type + 载荷摘要共同绑定；同键相同载荷返回原 task，不同载荷冲突。去重索引不自动释放，防止旧工作尚在运行时重复触发；最终受控清理需要外部结果/保留周期证据，不能靠 TTL 自动放开未知副作用。任务相关文本、原始异常、用户 Memory 不写入错误字段；当前仅适用于管理员可访问、内容已审阅的任务。

租约使用 Redis TIME 而非客户端时间。旧 worker 不能凭早先 token 完成；取消与过期均阻断最终任务状态提交。业务实际副作用仍须自己具有第六批 publication fence/条件写，队列租约不是跨数据库事务。

## 3. 新增 `cloud/task_atomic_v9.py`

**文件功能：**为既有 CloudTaskQueue 提供 Lua 原子操作；只使用已经配置的 `redis.asyncio` client，不建立新 Redis 实例、不从网络请求选择前缀。公开函数仅由可信服务器调用，owner 不来自未经认证的 body。

```python
from __future__ import annotations

import hashlib
import json
import re
import secrets
from dataclasses import dataclass
from typing import Any

from aiagent.state.shared_state import SharedStateConflictError, SharedStateUnavailableError

_NAME = re.compile(r"[A-Za-z0-9_.:-]{1,128}\Z")
MAX_PAYLOAD_BYTES = 8192
MAX_RESULT_BYTES = 8192
MAX_QUEUE = 1000
MAX_TASKS = 10000
LEASE_MS = 30_000


class TaskConflict(SharedStateConflictError):
    pass


@dataclass(frozen=True)
class Submission:
    task_id: str
    created: bool
    status: str


def _checked(value: str) -> str:
    if not isinstance(value, str) or not _NAME.fullmatch(value):
        raise ValueError("task_identifier_invalid")
    return value


def _json(value: Any) -> str:
    return json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(",", ":"), allow_nan=False)


def _digest(value: Any) -> str:
    return hashlib.sha256(_json(value).encode("utf-8")).hexdigest()


def _prefix(prefix: str) -> str:
    # Hash-tag braces are forbidden: these scripts are supported on standalone Redis only.
    if not isinstance(prefix, str) or not prefix or len(prefix) > 200 or "{" in prefix or "}" in prefix:
        raise ValueError("task_prefix_invalid")
    return prefix.rstrip(":")


def keys(prefix: str, queue: str):
    prefix = _prefix(prefix)
    queue = _checked(queue)
    return (f"{prefix}:tasks:queue:{queue}", f"{prefix}:tasks:v9:leases:{queue}",
            f"{prefix}:tasks:v9:index:{queue}", f"{prefix}:task:")


_ENQUEUE = r'''
local function compatible(key, expected)
  local kind = redis.call('TYPE', key).ok
  return kind == 'none' or kind == expected
end
if not compatible(KEYS[1], 'hash') or not compatible(KEYS[2], 'hash')
  or not compatible(KEYS[3], 'list') or not compatible(KEYS[4], 'set') then return {'invalid'} end
local prior = redis.call('HGET', KEYS[1], 'id')
if prior then
  if #prior ~= 32 or not string.match(prior, '^[0-9a-f]+$') then return {'invalid'} end
  if redis.call('HGET', KEYS[1], 'digest') ~= ARGV[2] then return {'conflict'} end
  local status = redis.call('HGET', ARGV[9] .. prior, 'status')
  if not status then return {'invalid'} end
  return {'existing', prior, status}
end
if redis.call('LLEN', KEYS[3]) >= tonumber(ARGV[7]) then return {'queue_full'} end
if redis.call('SCARD', KEYS[4]) >= tonumber(ARGV[8]) then return {'index_full'} end
if redis.call('EXISTS', KEYS[2]) ~= 0 then return {'id_conflict'} end
local t = redis.call('TIME')
local now = tonumber(t[1]) * 1000 + math.floor(tonumber(t[2]) / 1000)
redis.call('HSET', KEYS[1], 'id', ARGV[1], 'digest', ARGV[2])
redis.call('HSET', KEYS[2], 'id', ARGV[1], 'type', ARGV[3], 'queue', ARGV[4],
  'status', 'queued', 'payload', ARGV[5], 'result', '', 'owner', ARGV[6],
  'request_id', ARGV[10], 'attempts', '0', 'max_attempts', '1', 'error', '',
  'last_error', '', 'dead_reason', '', 'worker_id', '', 'lease_token', '',
  'lease_until_ms', '0', 'created_ms', tostring(now), 'updated_ms', tostring(now),
  'created_at', tostring(now / 1000), 'updated_at', tostring(now / 1000),
  'unique_key', '', 'protocol', 'v9')
redis.call('SADD', KEYS[4], ARGV[1])
redis.call('RPUSH', KEYS[3], ARGV[1])
return {'created', ARGV[1], 'queued'}
'''

_CLAIM = r'''
local queue_type = redis.call('TYPE', KEYS[1]).ok
local lease_type = redis.call('TYPE', KEYS[2]).ok
if (queue_type ~= 'none' and queue_type ~= 'list')
  or (lease_type ~= 'none' and lease_type ~= 'zset') then return {'invalid'} end
local id = redis.call('LINDEX', KEYS[1], 0)
if not id then return {'empty'} end
if #id ~= 32 or not string.match(id, '^[0-9a-f]+$') then return {'invalid', id} end
local task = ARGV[1] .. id
if redis.call('TYPE', task).ok ~= 'hash' or redis.call('HGET', task, 'protocol') ~= 'v9'
  or redis.call('HGET', task, 'status') ~= 'queued' then
  return {'invalid', id}
end
local attempts = redis.call('HGET', task, 'attempts')
if attempts ~= '0' then return {'invalid', id} end
local t = redis.call('TIME')
local now = tonumber(t[1]) * 1000 + math.floor(tonumber(t[2]) / 1000)
local until_ms = now + tonumber(ARGV[4])
redis.call('LPOP', KEYS[1])
redis.call('HSET', task, 'status', 'running', 'worker_id', ARGV[2], 'lease_token', ARGV[3],
  'attempts', '1', 'lease_until_ms', tostring(until_ms), 'updated_ms', tostring(now),
  'started_at', tostring(now / 1000), 'updated_at', tostring(now / 1000))
redis.call('ZADD', KEYS[2], until_ms, id)
return {'claimed', id}
'''

_RENEW = r'''
local kind = redis.call('TYPE', KEYS[2]).ok
if kind ~= 'none' and kind ~= 'zset' then return redis.error_reply('invalid_lease_index') end
local t = redis.call('TIME')
local now = tonumber(t[1]) * 1000 + math.floor(tonumber(t[2]) / 1000)
if redis.call('HGET', KEYS[1], 'status') ~= 'running'
  or redis.call('HGET', KEYS[1], 'lease_token') ~= ARGV[2]
  or tonumber(redis.call('HGET', KEYS[1], 'lease_until_ms') or '0') <= now then return 0 end
local until_ms = now + tonumber(ARGV[3])
redis.call('HSET', KEYS[1], 'lease_until_ms', tostring(until_ms), 'updated_ms', tostring(now))
redis.call('ZADD', KEYS[2], until_ms, ARGV[1])
return 1
'''

_COMPLETE = r'''
local kind = redis.call('TYPE', KEYS[2]).ok
if kind ~= 'none' and kind ~= 'zset' then return redis.error_reply('invalid_lease_index') end
local t = redis.call('TIME')
local now = tonumber(t[1]) * 1000 + math.floor(tonumber(t[2]) / 1000)
if redis.call('HGET', KEYS[1], 'status') ~= 'running'
  or redis.call('HGET', KEYS[1], 'lease_token') ~= ARGV[2]
  or tonumber(redis.call('HGET', KEYS[1], 'lease_until_ms') or '0') <= now then return 0 end
redis.call('HSET', KEYS[1], 'status', ARGV[3], 'result', ARGV[4], 'error', ARGV[5],
  'lease_token', '', 'lease_until_ms', '0', 'updated_ms', tostring(now), 'finished_ms', tostring(now),
  'updated_at', tostring(now / 1000), 'finished_at', tostring(now / 1000))
redis.call('ZREM', KEYS[2], ARGV[1])
return 1
'''

_EXPIRE = r'''
local kind = redis.call('TYPE', KEYS[2]).ok
if kind ~= 'none' and kind ~= 'zset' then return redis.error_reply('invalid_lease_index') end
local t = redis.call('TIME')
local now = tonumber(t[1]) * 1000 + math.floor(tonumber(t[2]) / 1000)
local status = redis.call('HGET', KEYS[1], 'status')
if status ~= 'running' then redis.call('ZREM', KEYS[2], ARGV[1]); return 0 end
local deadline = tonumber(redis.call('HGET', KEYS[1], 'lease_until_ms') or '0') or 0
if deadline > now then redis.call('ZADD', KEYS[2], deadline, ARGV[1]); return 0 end
redis.call('HSET', KEYS[1], 'status', 'unknown', 'error', 'lease_expired_outcome_unknown',
  'lease_token', '', 'lease_until_ms', '0', 'updated_ms', tostring(now), 'finished_ms', tostring(now),
  'updated_at', tostring(now / 1000), 'finished_at', tostring(now / 1000))
redis.call('ZREM', KEYS[2], ARGV[1])
return 1
'''

_CANCEL = r'''
local qtype = redis.call('TYPE', KEYS[2]).ok
local ltype = redis.call('TYPE', KEYS[3]).ok
if (qtype ~= 'none' and qtype ~= 'list') or (ltype ~= 'none' and ltype ~= 'zset') then
  return redis.error_reply('invalid_task_indexes')
end
local owner = redis.call('HGET', KEYS[1], 'owner')
if not owner or owner ~= ARGV[2] then return 'not_found' end
local status = redis.call('HGET', KEYS[1], 'status')
if status ~= 'queued' and status ~= 'running' then return status end
local t = redis.call('TIME')
local now = tonumber(t[1]) * 1000 + math.floor(tonumber(t[2]) / 1000)
redis.call('HSET', KEYS[1], 'status', 'cancelled', 'lease_token', '', 'lease_until_ms', '0',
  'updated_ms', tostring(now), 'finished_ms', tostring(now),
  'updated_at', tostring(now / 1000), 'finished_at', tostring(now / 1000))
redis.call('LREM', KEYS[2], 0, ARGV[1])
redis.call('ZREM', KEYS[3], ARGV[1])
return 'cancelled'
'''


async def _eval(redis, script, key_list, *args):
    if redis is None:
        raise SharedStateUnavailableError("task_redis_required")
    try:
        return await redis.eval(script, len(key_list), *key_list, *args)
    except Exception as exc:
        # Redis may have committed before response loss; never automatically rerun a side effect.
        raise SharedStateUnavailableError("task_redis_outcome_unknown") from exc


def _decode(value):
    return value.decode("utf-8") if isinstance(value, bytes) else str(value)


async def enqueue(redis, prefix: str, *, queue: str, owner: str, task_type: str,
                  payload: dict, unique_key: str, request_id: str = "") -> Submission:
    queue, owner, task_type, unique_key = map(_checked, (queue, owner, task_type, unique_key))
    if request_id:
        _checked(request_id)
    if not isinstance(payload, dict):
        raise ValueError("task_payload_invalid")
    body = _json(payload)
    if len(body.encode("utf-8")) > MAX_PAYLOAD_BYTES:
        raise ValueError("task_payload_too_large")
    pending, _, index, task_prefix = keys(prefix, queue)
    unique = f"{_prefix(prefix)}:tasks:v9:unique:{_digest([queue, owner, unique_key])}"
    task_id = secrets.token_hex(16)
    fingerprint = _digest([queue, owner, task_type, payload])
    response = await _eval(redis, _ENQUEUE, [unique, task_prefix + task_id, pending, index],
                           task_id, fingerprint, task_type, queue, body, owner,
                           MAX_QUEUE, MAX_TASKS, task_prefix, request_id)
    parts = [_decode(x) for x in response]
    if parts[0] in {"created", "existing"}:
        return Submission(parts[1], parts[0] == "created", parts[2])
    if parts[0] in {"conflict", "queue_full", "index_full", "id_conflict"}:
        raise TaskConflict("task_" + parts[0])
    raise SharedStateUnavailableError("task_index_invalid")


async def claim(redis, prefix: str, *, queue: str, worker_id: str) -> dict | None:
    pending, leases, _, task_prefix = keys(prefix, queue)
    worker_id = _checked(worker_id)
    token = secrets.token_hex(24)
    response = await _eval(redis, _CLAIM, [pending, leases], task_prefix, worker_id, token, LEASE_MS)
    parts = [_decode(x) for x in response]
    if parts[0] == "empty":
        return None
    if parts[0] != "claimed":
        raise SharedStateUnavailableError("task_queue_invalid_or_mixed_protocol")
    try:
        record = await redis.hgetall(task_prefix + parts[1])
    except Exception as exc:
        raise SharedStateUnavailableError("task_claim_outcome_unknown") from exc
    decoded = {_decode(k): _decode(v) for k, v in record.items()}
    if decoded.get("lease_token") != token or decoded.get("status") != "running":
        raise TaskConflict("task_claim_lost")
    try:
        decoded["payload"] = json.loads(decoded["payload"])
    except (KeyError, ValueError, TypeError) as exc:
        raise SharedStateUnavailableError("task_record_invalid") from exc
    return decoded


async def renew(redis, prefix: str, *, queue: str, task_id: str, token: str) -> bool:
    _, leases, _, task_prefix = keys(prefix, queue)
    _checked(task_id)
    _checked(token)
    return bool(await _eval(redis, _RENEW, [task_prefix + task_id, leases], task_id, token, LEASE_MS))


async def complete(redis, prefix: str, *, queue: str, task_id: str, token: str,
                   status: str, result: dict | None = None, error_code: str = "") -> bool:
    if status not in {"succeeded", "unknown"}:
        raise ValueError("task_terminal_status_invalid")
    _checked(task_id)
    _checked(token)
    if error_code:
        _checked(error_code)
    if status == "succeeded" and result != {"code": "completed"}:
        raise ValueError("task_success_result_invalid")
    if status == "unknown" and result is not None:
        raise ValueError("task_unknown_cannot_have_result")
    body = _json(result) if result is not None else ""
    if len(body.encode("utf-8")) > MAX_RESULT_BYTES:
        raise ValueError("task_result_too_large")
    _, leases, _, task_prefix = keys(prefix, queue)
    return bool(await _eval(redis, _COMPLETE, [task_prefix + task_id, leases],
                            task_id, token, status, body, error_code))


async def cancel(redis, prefix: str, *, queue: str, task_id: str, owner: str) -> str:
    _checked(task_id)
    _checked(owner)
    pending, leases, _, task_prefix = keys(prefix, queue)
    return _decode(await _eval(redis, _CANCEL, [task_prefix + task_id, pending, leases], task_id, owner))


async def expire_running(redis, prefix: str, *, queue: str, limit: int = 64) -> int:
    if not 1 <= limit <= 256:
        raise ValueError("task_recovery_limit_invalid")
    _, leases, _, task_prefix = keys(prefix, queue)
    if redis is None:
        raise SharedStateUnavailableError("task_redis_required")
    try:
        seconds, micros = await redis.time()
        now = int(seconds) * 1000 + int(micros) // 1000
        ids = await redis.zrangebyscore(leases, "-inf", now, start=0, num=limit)
    except Exception as exc:
        raise SharedStateUnavailableError("task_redis_unavailable") from exc
    count = 0
    for raw_id in ids:
        task_id = _checked(_decode(raw_id))
        count += int(await _eval(redis, _EXPIRE, [task_prefix + task_id, leases], task_id))
    return count
```

**代码解释：**入队的占位、记录、索引与 RPUSH 是单次 Lua；重复请求比较类型与载荷，不使用过期 TTL 释放幂等键。领取把 LPOP 和 running/租约写在同次 Lua，消除旧 BLPOP 到 start 的丢失窗口；领取响应丢失则任务最终进入 unknown。续租、完成与过期都在 Redis TIME 下检查；过期扫描每次最多 64 条且 Lua 再判断，和续租竞争时不会覆盖新租约。

`unknown` 不是死信重试许可；取消也不能撤回已经发给对象存储/Provider 的工作。队列和索引容量是保护性初值，不是性能结论；队列索引和去重键暂不自动删除，达到上限必须按第 8 节经审阅恢复/清理。Redis Lua 不提供错误回滚，脚本在首次写入之前检查关键索引类型并且先读取再弹出候选，但 Redis OOM、ACL 配置错误等仍可能造成部分写入；上线前必须在隔离命名空间验证 key 类型、内存与 ACL，停旧版写入，并按下文的故障修复流程检查索引。成功结果只记录固定 `{"code":"completed"}`，不将外部业务正文或错误堆栈写入任务。

### 4.3 新增 `cloud/task_worker_v9.py`

**文件功能：**一个已领取任务的心跳、结果提交和异常处理。处理器必须由 Worker 的可信代码固定注册，不接受任务 payload 中指定 Python 路径或函数。

```python
from __future__ import annotations

import asyncio
from collections.abc import Awaitable, Callable

Handler = Callable[[dict], Awaitable[dict]]


async def process_claim(queue, task: dict, handlers: dict[str, Handler]) -> str:
    task_id = task["id"]
    queue_name = task["queue"]
    token = task["lease_token"]
    handler = handlers.get(task["type"])
    stopped = asyncio.Event()
    lost = asyncio.Event()

    async def heartbeat():
        while not stopped.is_set():
            try:
                await asyncio.wait_for(stopped.wait(), timeout=5)
                return
            except TimeoutError:
                pass
            try:
                if not await queue.renew_v9(queue=queue_name, task_id=task_id, token=token):
                    lost.set()
                    return
            except Exception:
                lost.set()
                return

    pulse = asyncio.create_task(heartbeat())
    try:
        if handler is None:
            outcome, result, error = "unknown", None, "handler_not_approved"
        else:
            try:
                value = await handler(task["payload"])
                if not isinstance(value, dict) or value.get("ok") is not True:
                    outcome, result, error = "unknown", None, "handler_result_unconfirmed"
                else:
                    outcome, result, error = "succeeded", {"code": "completed"}, ""
            except asyncio.CancelledError:
                raise
            except Exception:
                # External outcome may be unknown even if the handler raised.
                outcome, result, error = "unknown", None, "handler_outcome_unknown"
        if lost.is_set():
            return "lease_lost"
        committed = await queue.complete_v9(queue=queue_name, task_id=task_id, token=token,
                                             status=outcome, result=result, error_code=error)
        return outcome if committed else "lease_lost"
    finally:
        stopped.set()
        await pulse
```

**代码解释：**每五秒续租；续租失败不会重新入队。只有处理器明确返回 `{"ok": True}` 且 token/租约仍有效才写 succeeded，业务详细结果不存任务；任何外部异常标 unknown，不把 traceback 或用户资料存储到任务。Worker 被取消时不尝试虚报失败，租约过期后由 sweeper 标 unknown。`asyncio.to_thread()` 被取消也不等于系统线程停止，因此任何 handler 的实际副作用必须有自己的提交栅栏。

```python
async def main() -> None:
    _install_signal_handlers()
    concurrency = int(os.getenv("WORKER_CONCURRENCY", "1"))
    if not 1 <= concurrency <= 32:
        raise ValueError("worker_concurrency_invalid")
    workers = [asyncio.create_task(_worker_loop(index)) for index in range(concurrency)]
    stop_waiter = asyncio.create_task(_stop_event.wait())
    try:
        done, _ = await asyncio.wait([*workers, stop_waiter], return_when=asyncio.FIRST_COMPLETED)
        for worker in workers:
            if worker not in done:
                continue
            if worker.cancelled():
                raise RuntimeError("worker_unexpected_cancel")
            exc = worker.exception()
            if exc is not None:
                raise RuntimeError("worker_loop_failed") from exc
            if not _stop_event.is_set():
                raise RuntimeError("worker_loop_stopped_unexpectedly")
    finally:
        for task in [*workers, stop_waiter]:
            if not task.done():
                task.cancel()
        await asyncio.gather(*workers, stop_waiter, return_exceptions=True)
```

正常 SIGTERM 仍经现有 `_install_signal_handlers()` 设置 stop event。此代码不控制 Docker/Kubernetes 的重启间隔，必须在部署侧实际配置并验证退避；不把 worker 进程退出当成 API liveness 失败。

## 5. 输出协议的有界过期清理

### 5.1 新增 `aiagent/state/delivery_retention_v9.py`

**文件功能：**清理第七批已过期的输出快照、事件及 ACK，释放 24 份输出配额；保留最多 256 个短期墓碑，使清理后在墓碑有效期内仍返回 410。只操作**同一个主体根**，不删除音频文件、Memory、操作记录或撤销屏障。

```python
from __future__ import annotations

from typing import Any

from aiagent.state.execution_ledger import MAX_STATE_BYTES, ExecutionRejected, canonical
from aiagent.state.shared_state import SharedStateUnavailableError

TOMBSTONE_RETENTION_MS = 86_400_000
MAX_TOMBSTONES = 256


def validate_tombstones(root: dict[str, Any]) -> None:
    data = root.get("delivery_tombstones_v9")
    if data is None:
        return
    if (not isinstance(data, dict) or len(data) > MAX_TOMBSTONES
            or any(not isinstance(key, str) or not key or len(key) > 128
                   or type(value) is not int or value <= 0 for key, value in data.items())):
        raise SharedStateUnavailableError("delivery_tombstones_invalid")


def prune_expired_outputs(ledger, user_id: str, *, limit: int = 32) -> dict[str, int]:
    if type(limit) is not int or not 1 <= limit <= 64:
        raise ValueError("delivery_retention_limit_invalid")
    key = ledger.key(user_id)
    for _ in range(32):
        before, now = ledger.atomic.read(key)
        if not before:
            # Unlike ledger.transaction(), cleanup must never create a new root.
            return {"outputs_removed": 0, "tombstones_removed": 0, "capacity_blocked": 0}
        root = ledger._decode(before, user_id)
        validate_tombstones(root)
        tombstones = root.setdefault("delivery_tombstones_v9", {})
        outputs = root.get("delivery_v7", {}).get("outputs", {})
        removed_tombstones = 0
        removed_outputs = 0
        remaining = limit
        for output_id in sorted(tombstones):
            if remaining <= 0:
                break
            if now >= tombstones[output_id]:
                del tombstones[output_id]
                removed_tombstones += 1
                remaining -= 1
        blocked = 0
        for output_id in sorted(outputs):
            if remaining <= 0:
                break
            item = outputs[output_id]
            if now < item["expires_ms"]:
                continue
            if output_id not in tombstones and len(tombstones) >= MAX_TOMBSTONES:
                blocked = 1
                break
            tombstones[output_id] = now + TOMBSTONE_RETENTION_MS
            del outputs[output_id]
            removed_outputs += 1
            remaining -= 1
        after = canonical(root)
        if len(after.encode("utf-8")) > MAX_STATE_BYTES:
            raise ExecutionRejected("execution_state_quota_exceeded")
        if ledger.atomic.cas(key, before, after):
            return {"outputs_removed": removed_outputs, "tombstones_removed": removed_tombstones,
                    "capacity_blocked": blocked}
    raise ExecutionRejected("execution_contention_retry_exhausted")
```

**代码解释：**不扫描全 Redis，也不运行外部 I/O；每次最多处理 limit 个已过期条目。使用第六批原始 JSON CAS，与 ACK/新输出/撤销竞争时必须重读，避免删掉并发更新。特别使用 `atomic.read` + `_decode` + `cas`，而不是空 key 上的 `transaction()`，避免清理不存在用户时创建新 epoch。墓碑上限满时停止并报告，不用删除未过期墓碑强行通过。

## 6. 数据、备份和任务边界

| 数据 | 此次动作 | 未完成/必须避免 |
| --- | --- | --- |
| 输出事件/分段 | 1 小时到期后可受控 prune，另保留 24 小时墓碑 | 不声称删除实际音频文件或网络缓存 |
| 私有音频、图片 | 无物理删除代码 | 第六批部分撤销路径直接移除对象索引，不能再安全推断孤儿归属；先补持久 GC 清单、路径/租约/条件删除测试 |
| Memory 向量/图 | 保留第六批引用屏障与 `memory_gc` | 不在没有独立版本证明时删除可能被新记录引用的物理对象 |
| operation/session/call | 暂不删除 | 清除 operation 会改变旧幂等键语义；必须先设计和测试墓碑、活跃引用与恢复版本 |
| v9 task/unique | 暂不自动清理 | 未知外部结果可能仍在执行；保留索引满额拒绝，不解锁重放 |
| checkpoint/摘要 | 第八批暂停旧摘要复用 | 物理 saver 文件/Redis 空间仍存在，不能从清空指针推定已删除 |
| 备份 | 无自动恢复代码 | 保留独立删除墓碑、定义备份淘汰期、恢复后重新应用删除版本；现阶段未解决恢复复活 |

上述边界意味着本文件**尚未完成整个第九批**：物理资源 GC、可持久跨进程 Memory 批准/队列、可靠备份删除标记及重建发布 fence 仍需实现和真实验收。禁止为“完成批次”直接删整个 Redis 主体 key、调用 `FLUSHDB`、批量删私有目录或恢复不安全的 chat_turn 自动写入。

## 8. 运维与恢复限制

### 8.1 状态矩阵

| 故障 | 服务返回/任务状态 | 操作员动作 |
| --- | --- | --- |
| Redis 连接失败 | 503 或 Worker 报错退出，不切本地 | 排查独立 Redis，确认最后事务结果 |
| enqueue 写入后响应丢失 | 调用方无法知道结果 | 同一 owner/type/key/payload 查询或重复提交可得原 task；确认 Redis 恢复且脚本未发生部分写入 |
| Worker 领取后退出 | 租约到期后 unknown | 查外部系统的稳定记录或人工核对，不能自动重排队 |
| Provider 401/429/503/timeout | handler 失败则 unknown | 区分未发送与可能已发送；本批不默认对任何状态自动重试 |
| Redis OOM/ACL/key 类型错误 | 明确故障；Lua 不承诺异常回滚 | 暂停写入，核查单个 task、queue、unique、index；保留原始快照 |
| 用户取消/Memory 删除 | 不允许旧 capability 提交 | 物理工作可能继续；跨存储写入仍需在目标端校验 fence |
| 旧任务重试/手工死信 | 409 | 独立人工审阅，不使用历史接口强行复活 |

出错后不要直接删除 unique key。确认外部结果未知时，保持 unknown；如果将来支持重放，必须记录经授权的决定，验证任务 owner、payload 摘要、原 operation/epoch/generation/revision/deadline 与目标服务幂等能力。当前本文**没有**提供有这些保证的自动重放实现。

### 8.2 迁移与回滚

1. 在维护窗口关闭三个已知任务提交入口 `/cloud/tasks/knowledge/rebuild`、`/cloud/tasks/vision-characters/rebuild`、`/knowledge/rebuild` 以及 `/vision/characters/rebuild`，停止旧 Worker 并盘点所有 queued/running/dead；不要把旧任务直接塞到 v9 list。
2. 对旧 running 与未知外部结果逐项记录并人工确认；备份 Redis 和真实制品、记录版本及用户可见删除墓碑。`prefix:tasks:v9:*` 必须是新的空 namespace，旧 queue list 已安全排空。
3. 同时更新 API 与 Worker，确保所有 worker 使用 v9；本版 submit/handler 白名单均为空，重建请求返回 503。检查 `get/list` 等 Redis 不可用时不回本地。
4. 回滚前再次停止写入和 Worker，保留 v9 索引及 unknown 状态。旧 Worker 的 BLPOP/start 和自动 stale 重排队不可安全消费 v9 任务，因此不能简单回滚后把它们重新启动；必要时继续关闭任务入口。
5. 通过隔离测试和证据审批后才注册具备稳定发布栅栏的任务类型。由于本版没有跨进程持久批准协议，不得在 handlers 中加入 Memory 自动写入。

### 8.3 配置与容量

沿用已统一的 `REDIS_URL`、`REDIS_PREFIX`、`TASK_QUEUE_NAME`、`WORKER_CONCURRENCY`。无新增环境变量；`LEASE_MS`、`MAX_QUEUE`、`MAX_TASKS`、输出墓碑保留期是代码中的初始值，尚未压测，调整需要覆盖 API/Worker 一致性、真实故障与质量回归。默认 Worker 最小运行账户必须有对应 Redis Lua 命令权限；生产不得让其它服务写入或更改 v9 索引 key 的类型。

```python
    left = before.get("steady")
    right = after.get("steady")
    if not isinstance(left, dict) or not isinstance(right, dict):
        raise ValueError("benchmark_steady_missing")
    old_samples, new_samples = left.get("samples"), right.get("samples")
    if type(old_samples) is not int or old_samples < 1 or old_samples != new_samples:
        mismatched.append("samples")
    warmup_before, warmup_after = before.get("warmup"), after.get("warmup")
    if (not isinstance(warmup_before, dict) or not isinstance(warmup_after, dict)
            or type(warmup_before.get("samples")) is not int
            or warmup_before.get("samples") != warmup_after.get("samples")):
        mismatched.append("warmup")
    if mismatched:
        return {"comparable": False, "mismatched": mismatched, "metrics": {}}
    metrics = {}
    for name in ("p50_ms", "p95_ms", "success_p95_ms", "error_rate", "degraded_rate"):
        old, new = left.get(name), right.get(name)
        if (type(old) not in {int, float} or type(new) not in {int, float}
                or not math.isfinite(old) or not math.isfinite(new)):
            clean_old = old if type(old) in {int, float} and math.isfinite(old) else None
            clean_new = new if type(new) in {int, float} and math.isfinite(new) else None
            metrics[name] = {"before": clean_old, "after": clean_new, "delta": None, "relative_change": None}
            continue
        metrics[name] = {"before": old, "after": new, "delta": new - old,
                         "relative_change": (new - old) / old if old != 0 else None}
    return {"comparable": True, "mismatched": [], "metrics": metrics,
            "source_sha256_before": before.get("source_sha256"),
            "source_sha256_after": after.get("source_sha256"),
            "token_usage": None, "cost": None, "server_cpu": None, "server_rss": None,
            "quality_regression": "not_evaluated"}


def main(argv=None):
    parser = argparse.ArgumentParser()
    parser.add_argument("--before", type=Path, required=True)
    parser.add_argument("--after", type=Path, required=True)
    args = parser.parse_args(argv)
    before = json.loads(args.before.read_text(encoding="utf-8"))
    after = json.loads(args.after.read_text(encoding="utf-8"))
    result = compare(before, after)
    print(json.dumps(result, ensure_ascii=False, indent=2, allow_nan=False))
    return 0 if result["comparable"] else 2


if __name__ == "__main__":
    raise SystemExit(main())
```

**代码解释：**差值是新值减旧值，负延时差不自动宣称“优化有效”；两个样本量相同也不保证统计显著。源码摘要作为变化证据保留但不要求相等；配置、fixture、并发、机器平台、Python 和目标 origin 不一致时拒绝比较。服务端 CPU/RSS、Token、费用和第四批质量指标在此均显示 unavailable/not_evaluated，必须另行采集，不填 0。模型版本及实际硬件虽可能未出现在原第六批 JSON，仍必须在报告外附环境证据；缺少这些证据不能用于发布结论。
